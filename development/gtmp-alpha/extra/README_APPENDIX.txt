
Отчёт для разработчика
----------------------
После прогона запустите MiusMultiplayer\Collect_Logs.bat: он соберёт один файл
MiusMultiplayer\GTMP_alpha_log.txt — система, версия игры, хеши установленных
файлов, переменные MP_*, отчёт Check_Install, выжимка по событиям и полные логи
игры. Присылайте именно этот файл, по одному с каждого ПК.
