# Зафиксированные исходники protocol 17 (1.0.7)

Эти три файла нужны **только** для стенда совместимости старого и текущего событийного
потока без игры. Они не входят в игровой модуль и не являются актуальными исходниками.

Происхождение: `development/net-v21/src/` коммита
[`16a88052d2b426460e361c68ba1c012ad9792ed0`](https://github.com/LilSgtLushkin/MiusVitals/tree/16a88052d2b426460e361c68ba1c012ad9792ed0/development/net-v21/src).
Файлы были извлечены из опубликованного review-export 1.0.7, SHA-256 полного текстового
экспорта `2435e1225ed047d97b834b716185ca0feb2de58725c1c5adc62b94806561e990`;
их содержимое дополнительно сверено с указанным Git-коммитом. Полный экспорт сохраняется
в истории Git и больше не дублируется в рабочем дереве.

Контрольные суммы LF-байтов:

| Файл | SHA-256 |
|---|---|
| `shots.cpp` | `7345597d535340f3e27664749dcc659a0376ddc043d8738a424364f1c4b18f08` |
| `xlate.cpp` | `a21315034a5fd9773af6757db1c64d2b5abb8ae1668c22b8c3c296c66b758e3e` |
| `protocol.h` | `b07f632c28651cf0cd6c5ebe6f56e54f39217c52c6c227f09b1ff2ebf34dddd5` |

`tools/extract_legacy_shots_fixture.py` перед сборкой заново проверяет каждый хеш и
копирует файлы в `build/`. Текущий исходник модуля ушёл на wire tag 18, поэтому
совпадения заголовков больше нет и не требуется: межверсийная совместимость не является
целью, а эти файлы — неподвижная ссылка на поток событий 1.0.7, а не контракт, который
обязан соблюдать текущий исходник. Инструмент сообщает расхождение тегов в логе, но не
считает его повреждением. Изменение **самих закреплённых байтов** по-прежнему отказ:
хеш проверяется первым, и подмена любого из трёх файлов требует отдельного решения и
пересмотра теста.
