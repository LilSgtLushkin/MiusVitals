его замену. Существующие установочные архивы и откат не менялись.

Имя каталога отсылает к используемой в проекте карте смещений сборки 3598/1. Это удобная метка
справочного снимка, а не доказательство совместимости всех смещений с другими установками. При
перехвате по-прежнему нужны проверки байтов конкретного загруженного модуля.

## Проверка целостности

```sh
python development/game-build-3598-1/manifest.py --verify
```

[`MANIFEST.txt`](MANIFEST.txt) фиксирует SHA-256, размер и поля PE всех 19 файлов. PE timestamp —
поле бинарного файла, а не обязательно дата его сборки (например, для воспроизводимой сборки он
может выглядеть как дата в будущем). `manifest.py --write` пересоздаёт манифест; применять его
следует только при намеренной замене снимка.
