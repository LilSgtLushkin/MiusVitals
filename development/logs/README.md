(хост и клиент). **В git лежит не больше 4 последних архивов** — при появлении новых самые старые
удаляются. Всё остальное можно достать из истории Git.

## Как читать

* `net_v21_opgame.log` — операционная карта, `net_v21_tacgame.log` — тактический бой;
  `*.prev.log` — предыдущий прогон; `basic_network_*_<pid>.log` — лог модуля отдельного процесса.
* Отметки `battle` — события боя, `module` — решения модуля, `boot` — флаги запуска.
* Ключевые строки: `versus`, `welcome from the host`, `a player joined`, `ceasefire`,
  `time scaled by`, `net: 5 s:`.

## Ротация

При новой выгрузке: положить архив сюда, удалить самый старый, обновить таблицу выше.
Распаковывать в репозиторий не нужно — содержимое не коммитится.
