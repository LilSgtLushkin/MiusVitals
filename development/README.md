# Файлы разработки — не для установки

`kit-source/` — каноническая редактируемая исходная структура MiusVitals v7.4.0. В ней находятся manifest сборки, средства проверки, исходный код и входные файлы комплекта игрока. **Не копируйте эту директорию в папку игры.**

Для установки в игру скачайте и распакуйте только [`../MiusVitals_v7.4.0_INSTALL.zip`](../MiusVitals_v7.4.0_INSTALL.zip). В нём находится точный комплект игрока из 16 файлов с обязательным корнем `MiusVitals/`.

Архив создаётся и проверяется `../scripts/package_kit.py`.
